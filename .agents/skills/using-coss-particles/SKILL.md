# Coss UI Particles

Read [the upstream particle index](references/particles.md) to find patterns by component type and description. Fetch the linked JSON manifest for the full source and adapt it to the feature.

Use local imports from `@/components/ui`, semantic theme tokens, and Phosphor icons instead of the examples' Lucide icons. Follow the `using-coss-ui` skill for component composition and accessibility rules.
